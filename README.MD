## ✨ What is NextPaste?

NextPaste is a native macOS clipboard productivity app that makes repetitive copy-and-paste workflows dramatically faster.

Instead of constantly switching back and forth between applications, simply copy multiple items once and paste them sequentially with a single keyboard shortcut.

Perfect for:

* 👨‍💻 Developers
* 🎨 Designers
* 📊 Data entry
* 📧 Customer support
* ✍️ Writers
* 🚀 Power users

# 🚀 Features

## ⚡ Sequential Paste

Copy multiple items.

Paste them one after another with a single shortcut.

Perfect for:

* Filling forms
* Coding
* Data entry
* Repetitive workflows

---

## 🔢 Paste by Number

Instantly paste your most recent clipboard items.

```
⌃ ⇧ 1
⌃ ⇧ 2
⌃ ⇧ 3
...
⌃ ⇧ 9
```

---

## ➕ Append Mode

Collect multiple clipboard items into one.

---

## ⌨️ Keyboard First

Everything is designed around keyboard shortcuts.

No mouse required.

---

## 🎯 Action View

Quickly navigate clipboard items and actions without interrupting your workflow.

---

## 🔒 Privacy First

Your clipboard belongs to you.

* No cloud sync
* No analytics
* No tracking
* Everything stays on your Mac

# 🛠 Installation

## Download

Download the latest release from the Releases page.

Or build from source.

---

## Build

```bash
git clone https://github.com/3llomi/nextpaste.git

cd nextpaste

open NextPaste.xcodeproj
```

Build using the latest version of Xcode.

# ⌨️ Default Shortcuts

| Action           | Shortcut                  |
| ---------------- | ------------------------- |
| Clipboard History | Command + Shift + C |
| Paste Item 1     | Ctrl + Shift + 1          |
| Paste Item 2     | Ctrl + Shift + 2          |
| ...              | ...                       |
| Paste Item 9     | Ctrl + Shift + 9          |
